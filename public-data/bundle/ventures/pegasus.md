# 무엇인가

PEGASUS는 [life-plan](../identity/life-plan.md)의 종착 벤처 — **UAM(도심/지역 항공 모빌리티) + 무인기(드론/UAV) + 항공사 + 항공우주**를 아우르는 항공 지주 비전. 슬로건 "상상을 현실로 / AIRBORNE." 전 모빌리티를 전기(On_E)로 운영한다는 친환경 원칙. ^[archive/2026-07-09-pegasus.md]

파일럿 꿈이 창업 꿈보다 먼저였고([founder](../identity/founder.md)), PEGASUS는 그 꿈을 사업의 형태로 우회 실현하는 그릇이다.

# 핵심 테제 (durable)

- **지역 항공 모빌리티 = 토이마켓이 아니라 대체시장.** 100~800km 구간은 운전하기엔 멀고 항공사가 경제성 있게 잇기엔 짧다 — 인류에게 좋은 선택지가 없는 구간. "air taxi"로 취급되는 이 시장은 사실 여행 티어 전체의 대체시장. 어려운 건 기체가 아니라, 모두가 **도시(city)가 아니라 지역(region)을 위해 설계하지 않는다는 점**. ^[archive/2026-07-22-belief-reconciliation-session.md] ^[archive/2026-07-21-thiel-fellowship-지원서-작성.md]
- **기술보다 제도/법 관통이 핵심.** "엄청난 기술력보다는 제도나 법을 관통 가능하느냐가 핵심" — 규제 통과가 UAM 상용화의 진짜 병목이라는 자기 통찰. ^[archive/2026-07-09-pegasus.md]
- **기체 컨셉**: fan-in-wing 하이브리드 VTOL. 초기 구상명 "ELLA"(POD 수평 유지·모터부만 틸트, 500kg+, 배터리 안전·소음 저감·낙하산). 이후 구체화된 설계명 **AERON-X8 FIW** — Skywalker X8 계열 블렌디드 플라잉 윙 + Fan-in-Wing 리프트 팬 4기 + 후방 푸셔 + TVC 노즐, HOVER↔CRUISE 천이 구조. ^[archive/2026-07-09-pegasus.md] ^[archive/2026-06-10-pegasus-fable5.md] ^[archive/2026-07-22-belief-reconciliation-session.md]

# 7년 실행 타임라인 (배터리→수소 공용 플랫폼)

핵심 설계 전략: **하나의 기체 형상에 배터리 버전과 수소 버전을 모두 담는 공용 플랫폼** — 처음부터 수소 탱크 공간을 확보한 채 배터리 모델을 설계해, 배터리로 먼저 상용화하고 같은 프레임에 수소 파워트레인을 이식(공기역학 인증을 간소화하는 Delta Certification). 3단계: ① 1–2년차 형상 동결(CFD)·축소기 비행 ② 3–5년차 실물 시제기·초도비행→**도심형 50km 배터리 모델 형식인증(TC)·상용화(매출 시작)** ③ 6–8년차 **광역형 300km 수소 모델** 인증→서울-대전·서울-부산 장거리 노선. ^[archive/2025-11-23-pegasus-7년-계획.md]

# PEGASUS Airlines & 브랜딩

항공사는 터키 LCC **Pegasus Airlines를 인수해 이름만 사용**하는 구상. UAM + 항공기 2개 서비스, Airbus 기체 + Rolls-Royce 엔진, StarLux 유사 프리미엄 컨셉(전체 세미비즈니스), Native App 기반. 브랜딩 키워드: 미래지향·혁신·절제, 컬러 = 세라믹 화이트·네이비 블루·골드(애플식 무결점 감성). "가끔 내가 파일럿으로 비행"이 명시적 소망. ^[archive/2025-01-16-pegasus-airlines.md] ^[archive/2026-07-09-pegasus-branding.md]

# 사업 구조 (비전)

버티포트(허브)를 인프라로 삼아 집→허브→회사 옥상 3단 이동을 잇고, VVIP 의전·산업용(화재진압·군용·구조)·배달 드론·환경(해양 쓰레기 청소) 등으로 확장하는 플랫폼 구상. 시드 단계는 CEO 포함 최대 3인(필수: 프로그래머 + 기계공학자). 경쟁사 좌표: Airbus·Boeing·Volocopter·EHang·현대·한화. ^[archive/2026-07-09-pegasus.md]

> 세부 기체/포드 엔지니어링 브레인스토밍(도어 개폐 방식, 엠비언트 라이트 등)은 아이디어 단계라 여기 옮기지 않음 — 원문은 archive 참조.

# UAM 기반 LED 에어쇼 아이디어

드론 대신 직접 제작한 UAM 기체를 활용해 호버링 기반 LED 에어쇼(기업 로고 구현)를 기획 중이며, 낮 시간대에는 전투기 에어쇼 형태로 연계하는 아이디어를 구상하고 있다. ^[archive/2026-06-03-사용자-정보-요약.md]
