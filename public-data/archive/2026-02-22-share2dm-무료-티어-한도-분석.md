# Share2DM 무료 티어 한도 및 비용 발생 지점

> 마지막 업데이트: 2026-02-22

## 사용 중인 서비스

- Cloudflare Workers (백엔드)
- Supabase (DB + Auth) - 별도 프로젝트 2개 (prod + staging)
- Toss Payments (결제)
- Meta Graph API (Instagram DM)

---

## 서비스별 무료 한도

### Cloudflare Workers

| 항목 | 무료 한도 | 초과 시 비용 |
|------|----------|-------------|
| 요청 수 | **10만 건/일** (~300만/월) | $5/월 (Paid 플랜) |
| CPU 시간 | 10ms/요청 | $5/월 (Paid 플랜) |
| Cron Triggers | 5개 | Paid 플랜 포함 |
| Workers 수 | 100개 | Paid 플랜 포함 |

- 현재 Cron 2개 사용 중 (DM 큐 1분마다 + 빌링 매일 자정 UTC)

### Supabase

| 항목 | 무료 한도 | 초과 시 비용 |
|------|----------|-------------|
| DB 용량 | **500MB** | $25/월 (Pro) |
| Auth MAU | 5만 명 | $25/월 (Pro) |
| Edge Functions | 50만 건/월 | $25/월 (Pro) |
| 스토리지 | 1GB | $25/월 (Pro) |
| 대역폭 | **5GB/월** | $25/월 (Pro) |
| 실시간 동시접속 | 200명 | $25/월 (Pro) |
| 프로젝트 수 | **2개** | $25/월 (Pro) |

- 현재 prod + staging 2개로 **프로젝트 수 한도에 이미 도달**.

### Meta Graph API (Instagram)

| 항목 | 한도 | 비용 |
|------|------|------|
| API 호출 | 무제한 | **무료** |
| DM 전송 | 200건/시간 (계정당) | **무료** (rate limit) |
| Webhook | 무제한 | **무료** |

### Toss Payments

| 항목 | 비용 |
|------|------|
| 기본료 | 없음 |
| 거래 수수료 | 결제 건당 ~2.2% + ₩100 |
| 테스트 모드 | 무료 |
